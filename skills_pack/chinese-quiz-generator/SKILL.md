# 國語科考題命題與測驗生成器 (Chinese Quiz Generator)

本 Skill 用於協助教師針對國小國語課程（南一版/翰林版/康軒版）設計高品質、結構嚴謹且符合教學目標的測驗考卷。
**適用於各年級（1–6 年級）、各版本**，不綁定特定專案資料夾。

---

## 0. 素材正確性鐵則（最高優先，違反則整份試卷作廢）

出題的第一要務不是格式好看，而是**題目本身不能有錯**。以下規則凌駕於所有其他步驟：

1. **素材必須有出處，禁止憑記憶生成**。
   題目中出現的每一個生字、語詞、成語、句型、注音，都必須來自**實際讀取過的檔案**。
   絕不可依印象「這一課應該有教」而自行填入——不同版本、不同年份的課文收錄範圍不同。
2. **找不到素材就停下來問，不要硬出**。
   若檢索不到該課的生字語詞檔，必須明確告知使用者「找不到 ○○ 的素材」並詢問，
   例如請使用者提供課本頁面、指定檔案，或確認版本年級是否正確。**寧可不出，不可猜**。
3. **注音一律查證**。
   標注讀音前必須以教材檔案或教育部重編國語辭典（`https://www.moedict.tw/uni/字` 或辭典網站）確認。
   同一個字在不同語詞中可能不同調（如「著急」與「著涼」），**不可由某一詞的讀音類推到另一詞**。
4. **答案唯一且無爭議**。
   每題作答前自問：有沒有第二個選項也講得通？形近字題的干擾項是否真的錯？
   語詞題的情境是否只容許一個答案？有疑慮就換題。
5. **卷末必須列出素材來源檔案**（檔名＋路徑），讓使用者可回頭核對。

## 核心流程 (Workflow)

當收到「出考題 / 命題 / 出測驗題」等需求時，請依據以下步驟執行：

### 1a. 確認出題範圍與檢索素材（跨年級／跨版本通用）

先確認三件事：**版本**（南一／康軒／翰林）、**年級與冊別**（如四上）、**課次**。
使用者若已在訊息中言明或當前專案已隱含（如專案名為「國語4上」），可直接沿用並在回覆中複述確認。

接著在**當前工作目錄的專案**中檢索該課素材，依這個順序找（各專案命名不同，用關鍵字比對而非固定路徑）：

| 要找的素材 | 檔名／資料夾常見關鍵字 |
| :--- | :--- |
| 生字、習寫字 | `生字`、`生字表`、`生字語詞`、`字詞習寫` |
| 字音字形、形近字、多音字 | `字音字形`、`字音`、`形近字` |
| 語詞與造句 | `字詞句練習`、`詞語解釋`、`語詞` |
| 延伸成語、四字語詞 | `成語`、`四字語詞` |
| 句型 | `句型`、`語句練習`、`句型總表` |
| 課文本文 | `課文`、`課文word` |

若專案內有結構化索引檔（如 `resources_index.json`、`unit_standards.json` 之類），優先使用索引查路徑。
**檢索完成後，向使用者列出實際讀到的檔案**，再進入下一步。

### 1b. 範例與參考資料檢索與確認 (Reference Template Inspection & Confirmation)
1. **嚴禁自行自創大題與題型結構**。題型一律取自「考題參考題型範例庫」，依序尋找：
   1. 當前專案的 `考題參考/` 資料夾；
   2. 找不到時，改用**主範例庫** `D:\備課ai\國語4上_115備課資源\考題參考\`
      ——這個資料夾是**跨年級、跨版本共用的題型範例庫**，出任何年級的考卷都可以取用其中的題型格式；
      使用時要告知使用者「本專案無範本，改用主範例庫」。
   3. 兩處都沒有，才退回本 Skill 下方的〈題型範本參考〉。
2. **每次都要實際列出資料夾中的全部檔案，不可憑記憶列舉**。
   這個範例庫會持續新增不同類型的出題參考，寫死檔名會漏掉新加入的範例。
   讀取後要說明每一份的**大題格式**（那是它被收錄的用途），供使用者挑選。
3. **題型結構與內容類別解耦原則（Format vs Content Decoupling）**：
   - 範本檔代表的是**「排版與測驗呈現題型（Format）」**（例如：情境代號選填題、單選選擇題），**不代表內容被鎖定**。
   - 若使用者要求「**字音字形／生字語詞**」測驗，選填題選項盒 `(A)~(J)` 應填入當課 **目標生字／生字語詞**。
   - 若使用者要求「**成語測驗**」，選填題選項盒才填入當課 **延伸成語**。
   - 同理，**範本來自哪個年級不限制出題年級**：四年級題本的格式一樣可以用來出三年級或六年級的卷。
4. **務必先向使用者列出找到的範本檔及其大題格式，並詢問確認**，例如：
   - 「*已找到範本資料夾，包含以下範本檔：*
     *1. `成語考題填空範例.pdf`（大題格式：【情境應用代號選填題】— 可根據需求填入生字語詞或成語）*
     *2. `115年縣市學習能力檢測題本四年級國語科題本.pdf`（大題格式：【語文知識單選題】）*
     *請問您希望參考哪一份檔案的大題格式進行出題？*」
   - 範本若標示了年級（如「四年級題本」）而使用者要出的是別的年級，仍可沿用其**格式**，但難度須配合實際年級調整，並在卷首註明。
5. **待使用者確認選擇的參考檔案與大題格式（例如輸入 `1` 或 `1.2`）後，才開始編排試卷**：
   - **嚴格對照原則**：僅能包含使用者所選範本檔相對應的大題格式，**絕不可擅自加載未被選擇的預設大題**。
6. **防洩題與選項分配彈性 (Anti-Leakage & Option Allocation)**：
   - 當同時存在「代號選填題」與「選擇題/改錯題」時，選項盒中的語詞／成語與後續大題答案絕不重複，避免交叉洩漏線索。

---

### 2. 語詞盤點與出題參數互動確認 (Vocabulary Inspection & Interactive Parameters)

**【本步驟為強制執行關卡，不可略過】**
在使用者確認範本檔與大題格式後、正式編排題目前，AI **必須主動執行以下互動確認流程**：

1. **盤點並呈現語詞與生字總清單**：
   - 檢索教冊/學習單資源，呈報該課/單元收錄的所有目標生字、形近字、語詞或成語總數。
2. **主動詢問出題參數（可搭配 ask_question 工具或明確選項標籤）**：
   - **總題數與大題比例**：詢問欲出題數（預設為 10~15 題，並提供大題配比選項，如 5題選填+5題單選、5題選填+10題單選等）。
   - **題目內容類型與偏好**：詢問命題偏好（如：全面涵蓋、著重形近字/易錯字辨析、或著重生活語境運用與修辭字義）。
   - **指定必考語詞/生字**：詢問是否有指定必出的生字或語詞。
3. **待使用者確認出題參數後，才開始進行試卷編排與題目產出**。

---

### 3. 考題結構規劃與選項均勻分布 (Test Paper Structure & Answer Distribution)

- **選擇題答案選項均勻分布原則 (Balanced Option Answer Keys)**：
  - 選擇題的正確答案選項（A, B, C, D）數量必須儘可能平均分布（例如 10 題時應配比為 3-3-2-2 或 2-3-3-2；5 題時配比為 2-1-1-1），避免集中或連續出現同一選項，確保測驗信度與公平性。
- **範本對照規範**：
  - 嚴格依據所選範本檔之大題格式出題，絕不自行添加未指定的大題。

---

### 4. 試卷編排與格式標準 (Layout Standards)

1. **試卷抬頭**：包含版本、年級、課次、課名、班級、姓名、得分欄。
2. **題目區**：字體清晰、題號明確、選項對齊、填空處預留足夠寬度 `（　　）`。
3. **解答與解析區**：附於卷末【教師專用】，包含正確答案與簡明解析，方便批改。
4. **資料來源與參考連結**：於回答結尾條列出所引用的教冊 PDF、學習單 DOC 或 JSON 索引檔名與 Markdown 超連結（含 `file://` 路徑）。
5. **後續 Word 檔匯出詢問**：試卷與解答產出完成後，**必須於回答結尾主動詢問使用者**：「請問是否需要將此試卷匯出生成 Word 檔（.docx）以供列印或編輯？」

---

### 5. 出題後品質雙重審查機制 (Post-Generation Dual Audit Mechanism)

試卷產出前，AI 必須自動執行以下**四大審查關卡**：

1. **跨大題選項與填空交叉比對（Cross-Section Item Audit）**：
   - 檢查「選填題選項盒（A~K）」中的所有生字語詞／成語與其他題目解答，絕不交叉洩漏。
2. **題幹線索洩漏檢查（Stem Clue Leakage Audit）**：
   - 檢查題幹中是否洩漏其他題目的正確答案。
3. **幹擾項與選項覆蓋度審查（Distractor Coverage Audit）**：
   - 確保選項與幹擾項合理且無答案爭議。
4. **答案選項分布均勻度審查（Option Distribution Audit）**：
   - 統計並確認 A, B, C, D 正確答案數量均勻分配。

於【教師專用解答】末端，應顯示雙重審查通過標籤：
- `[x] 已通過防洩題自動審查（無選填選項盒與題幹答案交叉洩漏現象）`
- `[x] 已通過答案選項均勻分布審查（A: 3, B: 3, C: 2, D: 2）`

## 題型範本參考 (Question Templates)

### 題型 A：情境代號選填題（可填生字語詞、成語或修辭）
> **提示**：列出選項區 (A) (B) (C)...，並設計情境完整的填空句。
> 例（字音字形生字語詞情境）：
> > (A) 篇幅　(B) 樸素　(C) 繁榮  
> > 1. 這篇文章的（　　）太長，需要適當精簡。

### 題型 B：選擇題（修辭/字義/字音字形）
> 例：
> > (   ) 下列哪一組「 」中的字，讀音完全**相同**？  
> > (A) 瀰「漫」／「漫」長 (B) 臺灣「欒」樹／「變」化 (C) 樸「素」／盡「責」 (D) 烏「黑」／油「墨」

### 題型 C：錯別字診斷改錯
> 例：
> > 1. 這位將軍穿上鎧甲後，看起來英姿**換**發。（　煥　）

## 命題品質檢查清單 (Quality Checklist)

**素材正確性（最優先，未全部打勾不得出卷）**
- [ ] 每個生字／語詞／成語／句型都來自**實際讀過的檔案**，沒有任何一項是憑印象填入。
- [ ] 已確認版本、年級冊別、課次三者無誤。
- [ ] 題目中出現的注音都已查證（教材檔案或教育部辭典），未由某詞讀音類推到他詞。
- [ ] 檢索不到的素材已向使用者說明，而非略過或自行補上。

**題目品質**
- [ ] 題幹無歧義，選項無答案爭議；每題都自問過「有沒有第二個選項也講得通」。
- [ ] 出題前已盤點並向使用者展示目標語詞/生字清單。
- [ ] 已向使用者互動確認「總題數與大題比例」以及「題目內容類型／命題偏好」。
- [ ] 選擇題答案選項（A, B, C, D）分布平均（如 3-3-2-2 或 2-1-1-1）。
- [ ] 題目語詞與生字完全符合該課課本與教冊收錄範圍。
- [ ] 選填題內容已根據需求選擇生字語詞或成語，而非強制限定內容。
- [ ] 已通過「防洩題審查機制」（選填選項盒不包含選擇題解答）。
- [ ] 解答區有附上簡要解析與雙重審查狀態標籤。
- [ ] 結尾已明確標註引用的檔案資料來源超連結。
- [ ] 題目列出後已主動詢問使用者是否需要匯出生成 Word 檔（.docx）。
